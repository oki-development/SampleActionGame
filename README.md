# Sample Action Game

80 年代のアーケードゲームをお手本にした、2D のアクションゲーム「Sample Action Game」の公開サイトと配布物のリポジトリです。

- **公開サイト**: https://oki-development.github.io/SampleActionGame/
- **ダウンロード**: [Releases](https://github.com/oki-development/SampleActionGame/releases) (最新は Rust 版 Ver.02。旧バージョンの Java 版 Ver.01.00 ～ 01.06 もあります)

このリポジトリには公開サイトのファイル (HTML・画像など) だけがあり、ゲームのソースコードはありません。
サイトのファイルは作者の手元から更新しています。

Releases の「Source code (zip / tar.gz)」は GitHub が自動で付けるもので、このサイトのファイルが入っています。ゲームではありません。
